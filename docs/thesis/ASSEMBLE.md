# 把草稿粘进学校模板

仓库里的 `chapter-*.md` 是对着本系统写的素材，**不是**终稿。直接整目录粘进 Word / LaTeX 会有两处查重风险：和其他人用同一开源模板的毕业论文撞车，以及摘要、第 6 章、第 8 章自己跟自己重复。

按下面做，重复率会低一截，也不会把「待填」抄进正文。

## 必做

1. 用学校封面、页眉、目录和参考文献样式，不要沿用本目录的 Markdown 标题层级原样导出。
2. 删掉每章开头的「用法」引用块，那是给作者看的，不是论文正文。
3. 致谢里的〈姓名〉必须换成真实指导教师；不要整段抄网上的致谢。
4. 插图只用来源 [`SCREENSHOTS.md`](SCREENSHOTS.md) 的本机截图。仓库 `img/` 是空的，网上的 FastAPI Users / Items 图不要用。
5. 第 6 章数字只抄 `docs/evaluation/latest-results.md`（2026-07-23，`cb0ead1`）。消融表、三种模式对照在本机跑完之前保持「—」，不要编。
6. 参考文献从 [`references.bib`](references.bib) 导入后，删掉正文没引用的条目；缺的读过再补，不要从别的毕业论文整页粘。

## 建议改写、不要原样粘

这些段落在摘要、第 1 章和第 8 章里意思接近，粘进去之前各写一遍自己的句子：

- 「工程闭环，不是新检索公式」
- 固定句「资料不足，无法根据当前笔记本中的来源可靠回答。」——正文引用一次即可，摘要用「固定弃权句」
- Recall@5 / 97.1% / 88.2% / 894 ms / 5595 ms 只在摘要和第 6 章各出现一次，第 8 章不要再抄表

第 3 章和第 4 章也不要互相粘：第 3 章保留架构、ER 和接口表，第 4 章只写函数名、常量和失败路径。

## 不要写进终稿的句子

- 「本系统已防止提示词注入」
- 「已完成渗透测试」
- 「RAG 提高了准确率」（消融未跑完时）
- 「Recall@5 = 100% 说明检索算法有效」
- 真实反代域名、真实邮箱、密钥、用户上传原文

## 粘贴顺序

封面与摘要 → 第 1—8 章 → 参考文献 → 致谢 → 附录 A—E。附录只保留 STRIDE 全表、安全回归对照、评测口径和复现命令，不要把第 5、6 章再贴一遍。
