# 答辩口述提纲（约 5 分钟）

不要照着论文念。下面按时间切，每段只留口播句。数字只在第 4 段出现一次。

## 0:00—0:40　题目与范围

这是单用户笔记本里的受控检索问答，不是开放域聊天机器人。资料只有文本、Markdown 和能抽出文字的 PDF。不做 OCR、不做协作、不做独立向量库。要证明的是这条链能演示、能量、能复现，不是检索刷榜。

## 0:40—2:00　现场点三下

1. 上传一份演示资料，等到「已就绪」。
2. 选「仅依据资料」，问一个资料里写明的事实：流式正文下面挂来源、页码和摘录。补一句：模型报的 chunk 号如果不在这一轮检索结果里，后端会丢掉。
3. 再问一个资料里没有的问题：正文必须是那句固定的「资料不足……」。不要把它说成答错。
4. 若时间够：点会话旁的「学习计划」，再打开侧边栏「甘特图」。甘特图只聚合，不会自己生成。

第二账户打开同一笔记本 UUID，应该是 404，不是 403。

## 2:00—3:10　实现上多做的三件事

常见教程是「检索完把原文塞进提示词」。本系统多了三道服务端门闩：

- 系统规则和资料分开走，资料标成不可信；
- 引用 ID 必须能在本轮检索集合里对上号；
- `grounded` 没有存活引用就改写成固定弃权句，检索为空时连聊天模型都不调。

学习计划的天数和提醒门槛也是后端钳的，模型 JSON 不能直接入库。

## 3:10—4:10　评测怎么讲

7 份合成说明、34 道固定题、一次基线。来源级 Recall@5 是 100%，自动引用 97.1%，关键词筛查 88.2%。人工把 34 题都标成通过。有四道自动没对上：千分位逗号、近义词、两份语料都在讲持久化。那是指标口径，不是胡编。

100% 只说明这份自描述语料顶到头了，不能说检索算法强。消融表如果还是空的，就说「协议和命令已经接通，数字等本机隔离库再跑」，不要现场编百分比。

## 4:10—5:00　可能被追问

- **幻觉防住了吗？** 没有。防住的是假出处和密钥出浏览器。正文仍可能听注入的话。
- **为什么不用独立向量库？** 复现只想维护一套 Compose，不是说 pgvector 更好。
- **和 LangChain 教程有何不同？** 差别在引用白名单和弃权是强制分支，不是提示词装饰。
- **下一步？** 只填已留空的消融和三种模式对照。不把 OCR、协作、微服务说成必做。

屏幕上不要出现 `.env`、真实邮箱、真实供应商地址。截图不要用仓库 `img/`。
