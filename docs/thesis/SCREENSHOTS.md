# 论文截图清单

只拍当前 NoteLLM 界面。不要使用仓库 `img/`（那里曾是上游模板图，已清空），也不要使用网上的 FastAPI Users / Items 示例图。

在本机 `docker compose watch` 或生产环境登录后捕获。截图里不要出现真实邮箱、真实供应商地址、密钥或他人资料。演示数据用 `docs/demo/` 与 `backend/scripts/seed_demo.py`。
